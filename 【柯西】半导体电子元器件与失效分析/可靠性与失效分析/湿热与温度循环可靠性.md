# 方法知识图谱：湿热(THB)与温度循环(CCT)可靠性方法

## 1. 测试类型
| 测试 | 目的 | 失效型 |
|---|---|---|
| 湿热THB | 湿气腐蚀/离子迁移 | 漏电、腐蚀 |
| CCT温度循环 | 热机械疲劳 | 焊点/界面裂 |
| TST热冲击 | 界面 | 脱层 |

## 2. 关系
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | 湿热 | → | 腐蚀/离子迁移 |
| R2 | 温度循环 | → | 焊点疲劳 |

## 3. 知识要点
- 湿热与温度循环是车规可靠两大气候试验，观察腐蚀/疲劳/污染。
