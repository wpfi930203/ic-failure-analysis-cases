# 失效案例知识图谱：LED热机械疲劳失效

## 1. 元信息
| 字段 | 值 |
|---|---|
| 失效对象 | LED焊点/固晶 |
| 失效模式 | 热循环疲劳→裂纹/开路/光衰 |
| 根因 | CTE失配+热循环→反复应力 |

## 2. 机理
- CTE失配→温度循环剪应力
- 焊点/固晶界面裂纹萌生扩展
- 电阻增大→光衰→开路

## 3. 检测
- 电参数、金相剖面裂纹、X-Ray空洞

## 4. 改进
- 低膨胀基板/散热匹配、优化焊料、降低温变

## 5. 知识要点
- LED热机械疲劳=CTE失配+热循环→焊点裂纹。
