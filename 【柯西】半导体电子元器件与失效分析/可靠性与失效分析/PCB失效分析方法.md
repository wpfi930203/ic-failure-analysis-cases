# 方法知识图谱：PCB失效分析通用方法

## 1. 流程
| 步骤 | 手段 |
|---|---|
| 无功定位 | 阻测/ICT/CAM |
| 无损 | X-Ray/AOI/CT |
| 剖面 | 金相切片(孔/焊点) |
| 成分 | SEM/EDS |
| 电性 | 阻抗/漏电 |

## 2. 关系
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | 阻测 | → | 定位断点/短路 |
| R2 | 切片+SEM | → | 看缺陷形貌 |

## 3. 知识要点
- PCB FA用"阻测定位→无损→剖面→成分"链路确认。
