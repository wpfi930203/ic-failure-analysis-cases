# 失效案例知识图谱：LED黑化失效分析（基础版）

## 1. 元信息
| 字段 | 值 |
|---|---|
| 失效对象 | LED镀银支架/表面 |
| 失效模式 | 黑化、光衰 |
| 根因 | 硫化+卤素侵蚀镀银 |

## 2. 机理
- Ag+硫→AgS变黑；Ag+卤素→AgX发黑
- 封装材料微量S/Cl长期析出
- 环境硫卤积累
- 黑化→反射降→光衰

## 3. 检测
- SEM/EDS 检出S/Cl

## 4. 改进
- 抗硫化支架/镀层、低硫材料、防潮防尘封装

## 5. 知识要点
- 黑化根因=银被硫/卤化，治理于支架抗腐+低硫卤材料。
