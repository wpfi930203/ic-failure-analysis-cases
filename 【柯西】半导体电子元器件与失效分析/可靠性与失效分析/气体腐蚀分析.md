# 方法知识图谱：气体腐蚀失效分析

## 1. 腐蚀源
| 气体 | 对象 | 产物 |
|---|---|---|
| S | Ag/Cu | Ag2S/Cu2S |
| Cl | Ag/Al/Cu | AgCl/Al腐蚀 |
| Br/I | 金银镀层 | 卤化腐蚀 |
| 湿气O3 | 铜面 | 氧化蚀 |

## 2. 关系
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | 硫 | → | 银硫化黑化 |
| R2 | 氯 | → | 电化腐蚀 |
| R3 | 湿气 | → | 加速 |

## 3. 检测
- EDS/XRF检硫氯溴、离子色谱/FTIR定量、腐蚀模拟

## 4. 知识要点
- 气体腐蚀定位靠EDS+XRF元素识别，区分环境/材料源。
