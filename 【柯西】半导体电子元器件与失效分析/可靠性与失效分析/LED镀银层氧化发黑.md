# 失效案例知识图谱：LED镀银层氧化发黑

## 1. 元信息
| 字段 | 值 |
|---|---|
| 失效对象 | LED镀银支架 |
| 失效模式 | 银层发黑、反射低、光衰 |
| 根因 | 氧化/硫化/卤化→银层变质(Ag2O/Ag2S/AgX) |

## 2. 机理
- 银在硫/卤/湿气下生成黑色化合物→反射降、接触电阻变差

## 3. 检测
- SEM/EDS检S/Cl/O、XRF定量、横截金相看腐蚀深度

## 4. 改进
- 环保镀层/防镀、低硫湿气管控

## 5. 知识要点
- 银层黑化多由硫/卤/湿气，EDS/XRF定性锁定元素。
