# 失效案例知识图谱：连接器引脚虚焊——脏污+氧化

## 1. 元信息
| 字段 | 值 |
|---|---|
| 失效对象 | 304不锈钢镀镍引脚连接器 |
| 失效模式 | 虚焊/上锡不良 |
| 根因 | 引脚脏污+镀层氧化 |

## 2. 证据链
| ID | 手段 | 结果 |
|---|---|---|
| E1 | 外观 | NG部分虚焊 |
| E2 | 可焊性 | NG fail |
| E3 | FTIR | 异物类似Poly(Styrene:Methyl Methacrylate)92.43% |
| E4 | 共面度 | NG均NG |
| E5 | SEM | 引脚与焊料分层+助焊剂残留 |
| E6 | XPS | NG无Na/Cl、O↑，金属氧化物多 |

## 3. 关系
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | 分层+助焊剂 | 导致 | 虚焊 |
| R2 | 共面差 | 导致 | 空焊 |
| R3 | 脏污+氧化 | 弱化 | 可焊性 |

## 4. 改进
- 清洁引脚、防氧化密封、提升共面、优化助焊剂

## 5. 知识要点
- FTIR定位异物+XPS定量氧化；与翘曲型虚焊区分。
