# 方法知识图谱：铝基板导热系数测试方法与定义厘清

## 1. 结构
- 绝缘层+铜箔线路+铝基层
- 散热关键：铝基板导热系数

## 2. 测试方法
- 标准ASTM D5470；厚度取绝缘层间距

## 3. 定义厘清
| 数值 |
|---|
| 铝合金121-151 W/(m·K)；绝缘层1-2.5 W/(m·K) |
| 铝是绝缘层近100倍→热阻在绝缘层 |
| "铝基板导热=绝缘层导热" |

- "总导热系数"无意义，是伪指标

## 4. 覆铜板vs成品板
- 成品铜箔不均+白油→导热系数约为覆铜板一半
- 去白油后接近覆铜板

## 5. 建议
- 去白油+覆铜板状态测真实值

## 6. 知识要点
- 测铝基板用ASTM D5470关注绝缘层；成品板因白油+铜箔不均低约一半。
