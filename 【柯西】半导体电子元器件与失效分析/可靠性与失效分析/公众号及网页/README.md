### 实测证据

| 检查项 | 结果 |
|---|---|
| 知识库属性 | `visible_export_status=1`（IC失效分析库为 3，那一个可以导出） |
| 条目属性 | 611 条**全部** `can_fetch_content=false`、`access_status=1` |
| 逐类型实测 `fetch_media_content` | 公众号 / 网址 / 图片 / PDF **四种类型全部失败**，返回 `code 220030 该文件获取失败，请至ima内查看处理` |
| 限制范围 | **全库限制**，非本分类特有：另抽查「精选资料」「半导体厂商技术资料」「人工智能&机器人」「通往财富自由之路」等目录，条目同样 `can_fetch_content=false`，导出同样 220030 |
| 可替代路径：原始 URL | 条目元数据**不含原始链接字段**，无法改从原网页抓取（`introduction` 只是正文节选，偶尔正文内出现链接文本，但不是结构化字段） |
| 可替代路径：接口工具全清单 | 端点仅 9 个工具（fetch_media_content / search_knowledge / get_knowledge_list / get_knowledge_base_list / get_addable_knowledge_base_list / create_media / import_urls / add_knowledge / search_knowledge_base），**无导出接口** |
| 可替代路径：检索补全文 | `search_knowledge` 只返回简介（≤300 字）+ 高亮片段；实测高亮为空、命中率低，无法拼回原文 |
