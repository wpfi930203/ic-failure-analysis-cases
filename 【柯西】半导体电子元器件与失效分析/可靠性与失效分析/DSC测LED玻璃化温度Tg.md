# 方法知识图谱：DSC测定LED封装环氧树脂玻璃化温度(Tg)

## 1. 最佳条件
| 条件 | 推荐 | 机理 |
|---|---|---|
| 颗粒 | 研磨成粉，越小越好 | 传热∝面积；粒径大→热滞后 |
| 用量 | 10-15mg | 过大多热平衡差 |
| 升温 | 10-15K/min | 速率高→热滞后→Tg偏高 |
| 装填 | 压实 | 间隙小热滞后小 |

流程：N2(>99.9%,20mL/min)；15mg、10K/min、压实；通电30min。EP310→Tg=129.851℃。

## 2. 影响因素
| 实验 | 结论 |
|---|---|
| 颗粒vs粉末 | 粉末台阶明显 |
| 用量 | 15mg适中 |
| 升温5/10/15 | Tg 123.6/127.9/130.6℃ |
| 压实 | 压实>不压 |

## 3. Tg意义
- Tg低→耐高温差；Tg高→内应力大→伤引线。双刃剑。

## 4. 知识要点
- 关键粉末化+压实+适量；配N2防氧化。
