# 失效案例知识图谱：防震橡胶部分老化失效（发粘）

## 1. 元信息
| 字段 | 值 |
|---|---|
| 失效对象 | 防震橡胶金属结合件 |
| 失效模式 | NG位置老化发粘 |
| 根因 | 热+循环应力→分子链破坏→发粘 |
| 排除 | 外部溶剂诱导老化 |

## 2. 定量证据
- HS-GCMS：防老剂4010NA↓67.1%、防老剂丁↓30.6%
- GCMS：无润滑油→排除溶剂老化
- GPC：NG几乎全溶，溶出1万~8万分子量

## 3. 机理
- 热+应力→防老剂消耗→分子链断裂→低分子析出→发粘

## 4. 改进
- 提升抗热抗疲劳、增防老剂、降工况应力

## 5. 知识要点
- 老化发粘本质=防老剂消耗+链断裂；定量锚点4010NA↓67%。
