# 失效案例知识图谱：二极管焊接不良排查

## 1. 元信息
| 失效对象 | 二极管(贴片/插件) |
| 失效模式 | 空焊/虚焊功能异常 |
| 根因 | 焊盘氧化/共面/炉温不一致 |

## 2. 排查流程
- 外观AOI看润湿桥接空焊
- 可焊性/共面度测
- X-Ray看空洞
- 剖面看IMC

## 3. 关系
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | 焊盘氧化 | → | 不润湿 |
| R2 | 共面差 | → | 空焊 |
| R3 | 炉温 | → | 润湿质量 |

## 4. 改进
- 控锡膏/助焊剂活性、活化清洗焊盘

## 5. 知识要点
- 二极管焊接不良AOI润湿+共面+炉温三条主线排查。
