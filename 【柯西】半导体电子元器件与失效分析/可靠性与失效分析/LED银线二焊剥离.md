# 失效案例知识图谱：LED银线二焊剥离

## 1. 元信息
| 字段 | 值 |
|---|---|
| 失效对象 | LED银线二焊点 |
| 失效模式 | 二焊剥离→开路 |
| 根因 | 键合参数不足/表面污染→二焊粘附弱 |

## 2. 机理
- 一焊OK、二焊不良（温度/压力/超声不匹配）
- 焊盘污染/氧化→粘附弱
- 键合参数漂移→贴合不足

## 3. 检测
- 拉力(Wire Pull)、焊面SEM/EDS、键合参数对比

## 4. 改进
- 调键合温度/压力/超声、清洁焊盘、加强拉力抽检

## 5. 知识要点
- 银线二焊剥离根因=键合工艺+焊盘附着，拉力+EDS定位。
