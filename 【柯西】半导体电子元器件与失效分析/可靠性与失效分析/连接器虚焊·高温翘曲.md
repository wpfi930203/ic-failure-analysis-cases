# 失效案例知识图谱：连接器第9Pin虚焊——高温翘曲变形

## 1. 元信息
| 字段 | 值 |
|---|---|
| 失效对象 | 连接器第9Pin |
| 失效模式 | 虚焊，时通时不通 |
| 不良率 | 千分之3.5，第9Pin占80% |
| 根因 | 连接器高温翘曲变形 |
| 排除 | 尺寸匹配、IMC热量、Pin可焊性、板翘曲 |

## 2. 证据链
| ID | 手段 | 定量证据 |
|---|---|---|
| E1 | 填锡高度 | 中间高两边低；第9 OPEN |
| E2 | 尺寸 | Pin与孔径匹配正常 |
| E3 | Profile+切片 | 峰值240℃ IMC 2-3μm正常 |
| E7 | Pin动态翘曲 | 第9离焊面最远，高差0.05-0.08mm |
| E8 | 塑胶平面度 | 常温0.049→过1次0.096→2次0.115mm |
| E9 | Demo验证 | 排除板翘曲 |

## 3. 关系
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | 塑胶高温翘曲 | 造成 | 第9Pin离焊面最远 |
| R2 | 翘曲 | 使 | Pin未接触→虚焊 |
| R3 | 填锡高差+过炉变形 | 判定 | 高温翘曲主因 |

## 4. 改进
- 高热变温塑胶、降炉温、压紧治具、共面控制

## 5. 知识要点
- 填锡高差+塑胶过炉变形+失效Pin离焊面远→锁定高温翘曲。
