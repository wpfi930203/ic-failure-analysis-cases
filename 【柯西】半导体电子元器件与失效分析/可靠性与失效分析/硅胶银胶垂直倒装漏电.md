# 失效案例知识图谱：硅胶封+银胶粘垂直倒装LED漏电（银离子迁移）

## 1. 元信息
| 字段 | 值 |
|---|---|
| 失效对象 | 垂直倒装LED芯片（阳极底阴极顶） |
| 失效模式 | 漏电流/短路 |
| 根因 | 硅胶吸水→银胶受潮→银离子迁移→枝晶桥接PN结 |

## 2. 机理链
- 硅胶吸水→银胶受潮→银离子化→垂直电流引导→枝晶迁移→桥接PN结→漏电短路

## 3. 案例验证
- 芯片侧检出异常银元素 + 银颗粒枝晶状延伸扩散

## 4. 改进
- 用金锡共晶焊接替代银胶
- 灯具防水

## 5. 知识要点
- 垂直倒装+银胶=高风险，垂直电流引导银离子迁移到上方PN结，比水平芯片更易桥接。
