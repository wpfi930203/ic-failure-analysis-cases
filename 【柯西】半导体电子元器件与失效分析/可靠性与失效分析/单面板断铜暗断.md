# 失效案例知识图谱：单面板断铜/暗断

## 1. 元信息
| 失效对象 | 单面印制板铜箔/孔铜 |
| 失效模式 | 线路暗断、开路 |
| 根因 | 铜箔针孔/蚀刻过/机械应力断裂 |

## 2. 机理
- 铜箔针孔→后期氧化断裂
- 蚀刻过度→铜轨细→开路
- 孔铜/焊盘应力疲劳→断铜

## 3. 检测
- 阻测定位断点、金相断口、SEM

## 4. 关系
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | 铜箔针孔/氧化 | → | 断铜 |
| R2 | 蚀刻过度 | → | 开路 |

## 5. 改进
- 改善铜箔/蚀刻均匀性、加强铜厚检测

## 6. 知识要点
- 暗断=外观正常内断裂，阻测+显微定位查孔铜/蚀刻/氧化。
