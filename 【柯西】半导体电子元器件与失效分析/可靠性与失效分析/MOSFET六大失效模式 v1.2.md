# 失效案例知识图谱：MOSFET六大失效模式

## 1. 六大模式
| 模式 | 机理 | 判据 |
|---|---|---|
| M1 雪崩击穿 | 能量超耐量→寄生BJT开启→热失效 | EAS |
| M2 栅极氧化层击穿 | 过压/ESD损坏 | VGS、ESD |
| M3 谐振振荡 | 系统寄生谐振叠加 | 热点定位/频谱 |
| M4 体二极管 | 反向恢复失效 | Td(off) |
| M5 过热 | 散热不足 | 红外热点 |
| M6 泄漏变差 | 污染/阈值漂移 | 漏电流 |

## 2. 热点定位法
- 红外热像+显微定位热点→失效网格

## 3. 关系
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | 雪崩超限 | → | BJT开启失效 |
| R2 | 栅极过压 | → | 氧化层击穿 |
| R3 | 谐振 | → | 叠加失效 |
| R4 | 体二极管 | → | 反向恢复脆弱 |
| R5 | 热点 | 定位 | 失效点 |

## 4. 改进
- 选高EAS、优化栅驱动、抑制谐振、加强散热

## 5. 知识要点
- 六大模式覆盖雪崩/栅极/振荡/体二极管/热/泄漏；热点定位是共性判据。
