# 方法知识图谱：物理失效分析(PFA)

## 1. 流程
| 步骤 | 手段 |
|---|---|
| 外观/AOI | 目检 |
| 无损 | X-Ray/超声 |
| 电性 | I-V曲线 |
| 开封 | 化学/机械 |
| 剥层 | 逐层去金属 |
| 显微 | SEM/EDX |

## 2. 关系
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | 开封+剥层 | → | 露出内部 |
| R2 | SEM/EDS | → | 形貌/成分 |

## 3. 知识要点
- PFA层层缩小，结合电性+开封+显微确认机理。
