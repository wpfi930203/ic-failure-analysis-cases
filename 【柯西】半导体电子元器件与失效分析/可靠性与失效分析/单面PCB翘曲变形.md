# 失效案例知识图谱：单面PCB翘曲变形

## 1. 元信息
| 失效对象 | 单面PCB板 |
| 失效模式 | 板翘曲(不平)影响焊接装配 |
| 根因 | 材料/对称性/热CTE失配/上下面铜量不平衡 |

## 2. 机理
- 板芯与铜CTE不匹配→翘曲
- 单面铜层严重不对称→应力不平衡
- 压合固化应力残留、过回流加剧

## 3. 检测
- 共面度/平面度、热循环回弹、CTE测定

## 4. 关系
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | CTE失配 | → | 翘曲 |
| R2 | 铜不对称 | → | 应力不平衡 |
| R3 | 热冲击 | → | 翘曲加剧 |

## 5. 改进
- 选低CTE/对称叠构、减少过炉、控温

## 6. 知识要点
- 单面PCB翘曲主因铜层不对称+CTE失配。
