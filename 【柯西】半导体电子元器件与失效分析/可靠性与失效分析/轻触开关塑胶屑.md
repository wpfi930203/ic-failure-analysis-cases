# 失效案例知识图谱：轻触开关塑胶屑

## 1. 元信息
| 失效对象 | 轻触开关 |
| 失效模式 | 内部塑胶屑→接触不良 |
| 根因 | 成形毛刺/切屑进入开关内部 |

## 2. 机理
- 注塑毛刺/切屑进入接触区
- 异物阻隔触点/磨损→时通时不通

## 3. 检测
- 拆检异物、SEM/EDS、FTIR证实塑胶、接触电阻

## 4. 改进
- 加强成型清洁去飞边、防尘净化装配

## 5. 知识要点
- 轻触开关异物以成形塑胶屑常见，拆检+FTIR确认。
