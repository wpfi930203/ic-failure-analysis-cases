# 失效案例知识图谱：LED铝反射层含氯腐蚀

## 1. 元信息
| 字段 | 值 |
|---|---|
| 失效对象 | LED铝反射层 |
| 失效模式 | 腐蚀、光衰 |
| 根因 | 环境/材料含氯+湿气→铝阳极腐蚀 |

## 2. 机理
- Cl⁻+水→铝表面溶解蚀刻
- 湿气+氯离子→电偶腐蚀加速
- 反射层破坏→反射降→光衰

## 3. 检测
- SEM腐蚀形貌、EDS检出Cl、与正常对比

## 4. 改进
- 杜绝含氯辅料/清洗剂、防潮密封、低氯材料

## 5. 知识要点
- LED反射铝层受氯+湿气腐蚀→光衰；EDS检出Cl是判据。
