# 失效案例知识图谱：LED黑化失效分析（2018版）

## 1. 元信息
| 字段 | 值 |
|---|---|
| 失效对象 | LED镀银支架 |
| 失效模式 | 发黑、光衰、色漂移 |
| 根因 | 硫/卤气体侵入→镀银硫化/卤化变黑 |

## 2. 机理
- 含硫气体+Ag→Ag2S黑化→反射率下降
- 卤素+Ag→AgCl/AgBr→发黑导电腐蚀
- 密封材料释放硫卤→封闭腔富集加速
- 黑化→光通衰、色漂移、开路

## 3. 检测
- SEM外观、EDS/XRF检出S/Cl/Br、FTIR排查硫源

## 4. 关系
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | 硫 | → | Ag2S黑化 |
| R2 | 卤素 | → | 黑化盐 |
| R3 | 黑化 | → | 光衰 |

## 5. 改进
- 低硫无卤材料、气密封装、支架防硫处理

## 6. 知识要点
- 黑化主因=银硫/卤化腐蚀，治理于低硫无卤材料+气密封。
