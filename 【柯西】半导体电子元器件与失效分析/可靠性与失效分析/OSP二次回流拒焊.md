# 失效案例知识图谱：OSP二次回流拒焊

## 1. 元信息
| 失效对象 | PCB OSP焊盘 |
| 失效模式 | 二次回流拒焊 |
| 根因 | OSP膜一次回流/长时间暴露破坏氧化→可焊性下降 |

## 2. 机理
- OSP膜高温回流老化/热伤或长时间氧化
- 二次回流时氧化膜阻止润湿→拒焊

## 3. 检测
- 可焊性测试、EDS/XPS氧化层、表层分析

## 4. 关系
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | OSP降解/氧化 | → | 可焊下降 |
| R2 | 可焊下降 | → | 拒焊 |

## 5. 改进
- 控OSP膜厚度/时间、回流前置烘、缩短停线

## 6. 知识要点
- OSP拒焊主因膜氧化破坏，可焊性+表层氧化双向验证。
