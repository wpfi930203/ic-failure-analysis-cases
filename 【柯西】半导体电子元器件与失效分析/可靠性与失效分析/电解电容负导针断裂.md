# 失效案例知识图谱：电解电容负导针断裂

## 1. 元信息
| 失效对象 | 电解电容负导针 |
| 失效模式 | 导针断裂→开路 |
| 根因 | 焊接/装配应力或疲劳→根部断裂 |

## 2. 机理
- 引线成型受力→根部微裂
- 长期振动/热循环疲劳扩展
- 结合点劣化

## 3. 检测
- 电阻/容量开路、断口SEM疲劳辉纹、焊接剖面

## 4. 改进
- 控制引脚成型应力、焊接温度、抗振

## 5. 知识要点
- 负导针断裂多为成型/焊接应力+疲劳；SEM断口判据。
