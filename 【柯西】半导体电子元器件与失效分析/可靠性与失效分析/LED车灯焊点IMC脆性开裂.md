# 失效案例知识图谱：LED汽车灯焊点失效（IMC过厚脆性开裂）

## 1. 元信息
| 字段 | 值 |
|---|---|
| 失效对象 | LED汽车灯ESK散热器1R（NG/OK各1） |
| 失效模式 | 车灯不亮及微亮 |
| 根因 | 焊点孔洞异常 + IMC层过厚 → 界面脆性 → 脆裂 → 开路 |

## 2. 证据链
| ID | 手段 | 结果 |
|---|---|---|
| E1 | 外观 | OK/NG无明显异常 |
| E2 | X-Ray | NG焊球孔洞更多 |
| E3 | 电测 | NG的Y2灯珠与PCB开路 |
| E4 | 金相切片 | NG焊盘开裂 |
| E5 | IMC厚度 | NG IMC过厚增脆 |
| E6 | EDS | OK/NG元素无差异 |
| E7 | 综合 | 孔洞→疲劳；IMC过厚→脆裂 |

## 3. 关系
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | 焊点孔洞 | 导致 | 疲劳失效 |
| R2 | IMC过厚 | 增加 | 界面脆性 |
| R3 | 脆性 | 导致 | 脆裂 |
| R4 | 开裂 | 导致 | 开路不亮 |

## 4. 改进
- 补充润湿锡膏（含Ni遏制IMC）
- 调炉温曲线（降峰值/短回流）+氮气回焊
- 加强焊点可靠性检测

## 5. 知识要点
- 机理主线：孔洞→疲劳 + IMC过厚→脆裂→开路。
- 对策杠杆：Ni掺杂锡膏、炉温（峰值/时间）、氮气烘。
