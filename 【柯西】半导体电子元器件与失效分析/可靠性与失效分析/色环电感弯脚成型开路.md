# 失效案例知识图谱：色环电感弯脚成型开路

## 1. 元信息
| 失效对象 | 色环电感(轴向引线) |
| 失效模式 | 弯脚成型后开路 |
| 根因 | 弯脚应力致引线根部断裂/线圈断线 |

## 2. 机理
- 弯脚急躁→引线疲劳/过屈服裂
- 内端线圈结合薄弱→断开
- 腐蚀/氧化在应力集中处加速

## 3. 检测
- 电感/直流电阻开路、断面SEM、开封看线圈

## 4. 改进
- 控制弯脚半径/力度/温度、加强焊点

## 5. 知识要点
- 色环电感弯脚开路根因在成型应力+结合薄弱，SEM判弯痕。
