# 失效案例知识图谱：LED正极缺电流阻挡层

## 1. 元信息
| 字段 | 值 |
|---|---|
| 失效对象 | LED芯片正极 |
| 失效模式 | 漏电/光效异常 |
| 根因 | 电流阻挡层(IBCL)工艺缺失→电流聚集 |

## 2. 机理
- 缺阻挡层→电流注入不均集中
- 电流拥挤→局部发热/漏电
- 光效降、可靠差

## 3. 检测
- 电参数、发光均匀性、EL/漏电流

## 4. 改进
- 补齐阻挡层工艺、优化电流分布

## 5. 知识要点
- 正极缺阻挡层→漏电集中，工艺补齐为要。
