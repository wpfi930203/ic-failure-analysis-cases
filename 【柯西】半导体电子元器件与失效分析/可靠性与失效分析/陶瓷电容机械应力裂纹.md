# 失效案例知识图谱：陶瓷电容机械应力裂纹

## 1. 元信息
| 失效对象 | MLCC片式陶瓷电容 |
| 失效模式 | 体部裂纹→漏电流/断路 |
| 根因 | 机械应力(翘板/贴装/分板/热冲击)超陶瓷脆性强度 |

## 2. 机理
- 陶瓷脆性，受机械弯曲应力产生内部裂纹
- 裂纹沿端子/电极扩展→漏电/断路
- 区别于热应力裂纹：机械性多为板挠曲引起

## 3. 检测
- 外观裂纹路径、X-Ray/超声、断面金相、电测

## 4. 改进
- 优化贴装减少板弯曲、选耐弯大尺寸、回流后避免压力

## 5. 知识要点
- MLCC裂纹≠热裂，需辨机械应力源，定位板挠曲与裂纹路径。
