# 失效案例知识图谱：陶瓷电容失效机理

## 1. 主失效机理
| 机理 | 说明 |
|---|---|
| 介电击穿 | 高电场/工艺缺陷→漏电 |
| 机械裂纹 | 翘曲/热冲击→裂纹 |
| 电极迁移/劣化 | 银/钯电极迁移氧化 |
| 湿度/污染漏电 | 表面离子污染 |

## 2. 关系
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | 高电场 | → | 介电击穿 |
| R2 | 裂纹/污染 | → | 漏电 |

## 3. 检测
- 绝缘电阻/DF容值、切片显微、EDS

## 4. 改进
- 合理降额电压、防潮、选高可靠型

## 5. 知识要点
- MLCC失效主机理=介电击穿+机械裂纹+电极/污染漏电。
