# 失效案例知识图谱：开关电源PCBA焊点吹孔不良（基材疏松+吸潮+助焊剂残留）

## 1. 元信息
| 字段 | 值 |
|---|---|
| 失效对象 | 开关电源板（PCBA）多个焊点（DIP插件） |
| 失效模式 | 焊点吹孔不良：表面凹凸不平、内部空洞、残留物颗粒 |
| 背景诱因 | 存储期遇雨水天气、仓库湿度大 |
| 直接根因 | PCB基材疏松、孔壁粗糙 + 吸潮 + 助焊剂残留 |

## 2. 实体节点（证据链 E1~E5）
| ID | 手段 | 发现 |
|---|---|---|
| E1 | 外观检查 | 焊点周围吹孔异常、表面不规则凹凸 |
| E2 | 工业CT | NG插件焊点内部较大空洞，分布无规律 → 内填不足 |
| E3 | 切片+显微镜 | IIP孔焊料填充严重不足、孔壁粗糙、孔旁多处基材疏松、焊料内较大空洞 |
| E4 | SEM | 焊孔旁基材疏松、焊点内孔洞、过孔侧壁孔隙损伤 |
| E5 | EDS | 吹孔内存在助焊剂残留 |

## 3. 根因机理
| ID | 机理 |
|---|---|
| E6 | 基材疏松 → 焊料无法充分填充 → 空洞 |
| E7 | 孔壁粗糙 → 焊料填充差 → 空洞 |
| E8 | 吸潮 → 焊接水分汽化产气 → 加剧吹孔 |
| E9 | 助焊剂残留 → 产气吹孔 + 长期腐蚀/电阻增大风险 |

## 4. 关系三元组
| # | 头 | 关系 | 尾 |
|---|---|---|---|
| R1 | 基材/孔壁 | 降低 | 焊料填充 → 空洞 |
| R2 | 吸潮 | 汽化产气 | 加剧吹孔 |
| R3 | 助焊剂残留 | 产气/劣化 | 吹孔/长期可靠性风险 |
| R4 | 空洞+疏松 | 表现为 | 吹孔 |

## 5. 改进措施
| ID | 措施 |
|---|---|
| E10 | 改善存储环境防吸潮（湿度管控/防潮包装） |
| E11 | 改善PCB基材致密性与孔径工艺（降孔壁粗糙） |
| E12 | 优化助焊剂用量与清洗工艺减少残留 |

## 6. 数据缺口
- 空洞尺寸/数量定量、基材疏松程度量化、助焊剂残留面积：定性描述，null。

## 7. 知识要点
- 吹孔三机理（填充不足、气体排放、助焊剂逸气）可由基材/孔壁、吸潮、助焊剂残留三方叠加解释。
