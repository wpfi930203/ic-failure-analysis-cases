# 失效案例知识图谱：LED贴片灯珠回流焊空洞比过高

## 1. 元信息
| 字段 | 值 |
|---|---|
| 失效对象 | LED贴片灯珠锡层/散热焊盘 |
| 失效模式 | 空洞率高→死灯、开路、散热不良 |
| 空洞比标准 | 业内普遍要求<10%（IPC-7095类） |

## 2. 机理
- 加热时LED内夹住空气/助焊剂化合物膨胀→空洞

## 3. 案例
- 案例一：散热焊盘空洞>30%，冷热循环焊锡开裂开路
- 案例二：死灯率38%，孔面积>焊盘25%，排除驱动/散热
- 案例三：空洞40%→改进<10%部分0%，已量产

## 4. 空洞分布（26样本）
| 区间 | 占比 |
|---|---|
| 20-30% | 37% |
| 30-40% | 42% |
| 40%以上 | 12% |

## 5. 改进
- 优化回流焊曲线、助焊剂、镀层；X-RAY抽检

## 6. 知识要点
- 空洞率>10%→散热差/开裂/死灯；坏灯洞率高(25-40%)从回流焊工艺入手。
