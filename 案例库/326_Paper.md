## Fault Localization Using Dynamic Optical-beam  Induced Current Variation Mapping  

MH Thor, SH Goh, BL Yeoh, Hu Hao, YH Chan, and Zhao Lin  GLOBALFOUNDRIES, Technology Development, Product Diagnostic Engineering, Singapore   Email:   manhon.thor@globalfoundries.com

Abstract-   In this paper, we report a new dynamic laser stimulation  technique based on optical beam-induced current (OBIC)  variation mapping for global fault localization. A production  tester exercised the chip dynamically whilst a 1064 nm wavelength  laser rasters the region of interest through the silicon substrate.  The OBIC variation with test cycles is recorded for every scanned  pixel and translated into a current profile for pattern matching to  determine the suspected defect location. Unlike laser-assisted  device-alteration (LADA) which uses the same laser, this  technique applies to hard defects. Four case studies successfully  demonstrated the feasibility of this technique.

Keywords  – Fault Localization, Hard Defects, Dynamic OBIC,  LADA, Varation Mappings .

## I. I NTRODUCTION 

The use of 1064 nm wavelength laser for fault localization  and characterization has been well established several decades  ago. OBIC and LIVA are both static and dynamically-static  electrical fault isolation (FI) techniques. For conventional  OBIC, electron hole-pairs across junctions are generated by the  ionize laser beam. The induced current may be collected  through the power pin which is connected to a current amplifier  [1]. When a current is detected, the location of the light beam  determines the area of interest. FI using LIVA [2] works by the  same principle but differs by the use of a constant current bias  and detects the voltage change due to carrier stimulation. It  isolates defects that are connected to these junctions. The first  application of OBIC with functional testing of a chip was  reported by Wu [3]. The tester is set to a dynamic-static failing  state. However, it requires an additional OBIC detection system  as a voltage source and knowledge of the failing state as a  prerequisite.  For global FI of functional fails, this information  is usually not readily available and the entire test pattern of  interest is required to be  exercised in a loop manner while  performing FI concurrently [4, 5].

To address this limitation, we present a new approach using  standard dynamic FI setup as shown in Fig. 1. A scanning laser  interrogates the device under test while dynamic current from  the tester supply pins are monitored concurrently for varied test  cycles on each pixel. Dynamic current is defined as current  consumed by the DUT during test execution. Hence, since  different gates are activated with varying test vectors,  fluctuations in the current are expected. This is the reason why  the power pin cannot be coupled into a current amplifier for  conventional OBIC analysis.

This current information is saved into a log file. A  post-processing step which comprise generating a dynamic  current profile such as shown in Fig. 2 and the use of a  correlation function to compare the generated profile against a  reference, interprets this log file to produce a technical signal  image for FI.

Most contemporary integrated circuits (IC) are driven by  multiple power supplies. The current consumption of these  supplies varies dynamically throughout the test run. In general,  when laser stimulates the IC, supplies current increases. The  induced current is defined by the subtraction of supply base  current without laser stimulus from that with laser influence.  Fig. 3 shows the induced current at three selected vectors,  namely 5000, 250000 and 700000 under varied laser power  stimulation. In this example, it is evident that VDDC presents  the largest change in induced current with laser power and is  selected for monitoring. This is expected since laser stimulates  the memory cells and VDDC is the memory array supply. In  Fig. 4, the linear relationship of VDDC induced current against  laser power also confirm the OBIC effect.

## Case 2: Subtle increase in dynamic current  

The second case considers the situation where the increase in  dynamic current is not obvious. Fig. 6 illustrates an example.  The dynamic current profiles acquired at different locations  appear to be noisy, impeding any possibility to distinguish  abnormal sites. In this case, a post-processing step is required.  To formulate a method, the characteristic of dynamic current is

first studied. The dynamic current without laser stimulation is  acquired for multiple iterations from cycle 0-20k. Fig.7 shows  the results. It is found that the dynamic current fluctuations  assume a Gaussian behavior such that averaging is able to  suppress the noise by a theoretical factor of  $\sqrt{N}$   where  $N$   is the  number of averaged samples. In this example, a stable dynamic  current is achieved with at least 128 samples average. This  result proves that signal averaging is necessary in this scenario.  However, it is noteworthy that this threshold might defer  depending on devices and test environment.

In a previous work [7, 8], we implement a cross correlation  coefficient   $C_{N}$  to determine the match quality between two  signal profiles; a higher coefficient indicates better match  probability.  $C_{N}$   is defined as:

$$C_{N}=\frac{\sum(x-\bar{x})(y-\bar{y})}{\sqrt{\sum(x-\bar{x})^{2}\sum(y-\bar{y})^{2}}}$$

In this case, a similar method is deployed but is implemented  differently. Instead of seeking a match as in [7, 8], the inverse is  desired. The worse correlation coefficient indicates the possible  defect site.

## IV.  C ONCLUSION 

A new dynamic OBIC fault localization technique which  does not require additional detection system is presented in this  abstract. By incorporating a post-processing procedure, either  by thresholding or cross-correlation on the induced current  profile for every pixel, fault isolation can be achieved.  Experimental results demonstrate its feasibility. It is  noteworthy that 1340 nm wavelength laser was also tried in the  experiments but yield no successful outcome in localization.  Although this work focuses on memory defect, there are plans  to explore similar applications to digital logic and analogue  fails as well.
