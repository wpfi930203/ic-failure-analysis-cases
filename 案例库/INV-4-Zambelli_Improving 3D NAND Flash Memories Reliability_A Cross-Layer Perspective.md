## Improving 3D NAND Flash Memories Reliability: a  Cross-Layer Perspective  

Cristian Zambelli 1  and Rino Micheloni 2  1 Dip. di Ingegneria, Università degli Studi di Ferrara, via G. Saragat 1, Ferrara, Italy  2 Avaneidi, via G. Garibaldi 43, Saronno, Italy  Phone : +39-0532974993, Email : cristian.zambelli@unife.it

Abstract —The 3D NAND Flash memory technology is the  main building block of storage architectures such as multimedia  cards and Solid-State Drives. Applications ranging from mobile  to high-performance computing are continuously calling for an  increased storage density, requiring massive scaling efforts at  the device and array level. This leads to a natural degradation  of the functional metrics of the technology while exposing new  reliability issues that jeopardize the inherent memory trade-off  with performance. A simple device optimization would be  insufficient to tackle the problem. In this work, we show through  some case studies how a cross-layer approach spanning from  devices and circuits to system-level optimizations is mandatory  for future storage systems development.

Keywords—3D NAND Flash, reliability, randomization,  temporary read errors, ECC, Solid-State Drives (SSD)

## I.    I NTRODUCTION 

The 3D NAND Flash technology is the preferred option  for non-volatile mass storage solutions such as multimedia  cards (MMCs) and Solid-State Drives (SSDs) [1]. This  technology provides a notably higher storage capacity and  improved scaling features than its planar predecessor [2,3].  However, similar to planar NAND Flash, the 3D NAND Flash  technology faces reliability challenges such as wear-out  failures from repeated data writing/erasing (known as  endurance failures [4]), higher sensitivity to temperature in  both static (data retention [5]) and dynamic (cross-temperature  [6]) regimes, and disturbances caused by frequent memory  access on the same topological locations (e.g., read disturb  [7]). Additionally, new reliability threats are distinctive to the  physical characteristics of 3D devices [8,9]. All these  reliability issues manifest as a corruption of the bits storing the  information in the 3D NAND Flash after operation. The  number of corrupted bits per memory page is defined as Fail  Bits Count (FBC). This metric is intertwined with the  performance of a storage system while dictating its overall  reliability. Using complex Error Correction Code (ECC)  engines or secondary correction mechanisms in SSD/MMC  controllers allows for coping with the increasing FBC  throughout the memory's lifespan [10,11]. However, this  approach runs out of steam very quickly if transitioning  towards multi-bit per cell paradigms (i.e., Triple Level Cell –  TLC or Quad Level Cell – QLC) and no ECC co-design with  the memory is envisioned. State-of-the-art ECCs alone might  be insufficient to guarantee high inherent reliability since the  FBC could exceed the theoretical limit for data correction (i.e.,  Shannon's limit [12]). The 3D NAND Flash technology also  demonstrated that the most efficient way to outperform  traditional planar NAND is massively leveraging the 3D  integration concept by incorporating multiple layers through  stacking or multi-deck methods (see Fig. 1). This results in  large process variations yielding a complexity increase in the  reliability estimation process and control [13]. In this work, we present the reliability of a TLC 3D NAND  Flash memory through FBC characterization in different  working corners. ## III.   I MPROVING  3D   NAND   F LASH RELIABILITY 

In this section we demonstrate how to tackle several  reliability issues in 3D NAND Flash memories by  implementing circuit- or system-level solutions to mitigate the  FBC for future reliable storage architectures. Specific use  cases will be discussed having the relationship between  storage performance and reliability in mind.

## A.   Bidimensional randomization for write patterns  

Since the era of planar NAND Flash technology,  researchers observed that the FBC in endurance tests  evidenced a strong correlation between data corruption and  the pattern applied to write the data on the memory [18]. This  potentially aggravates the reliability in retention and read  disturb conditions since both build on top of the endurance.  Without decoupling the FBC pattern dependency from the  intrinsic 3D NAND Flash reliability it is easy to incur in some  unfortunate situations where FBC is higher than the correcting  capabilities of the ECC. A randomizer circuit is used in  storage devices to avoid those unwanted events. The goal of a  randomizer is to ensure that the memory data programming is  achieved in the most efficient way that makes statistically  negligible the probability of a worst-case data pattern. The  randomization process performs a transformation of the  original user data with an exclusive OR (XOR) operation  between the data path and the output of a Linear Feedback  Shift Register (LFSR) circuit initialized by a starting value  (i.e., a seed to initiate a pseudo-random process).

## B.   TRE consequences on storage and mitigation  

The TRE is a peculiar reliability issue of 3D NAND Flash  [8]. Its physical origin is speculated to be associated with the  nature of the poly-Si material used in the channel integration  [23]. The channel grain boundary traps (GBT) are filled  during the program operation. During the idle time, part of the  GBTs will discharge as the program voltage is disconnected  from the control gates of the memory cells. When the first  operation is experienced, the previously discharged GBTs will  cause the cells' threshold voltage to lower, resulting in a high  FBC. After the first read operation, previously discharged  GBTs are re-filled because of the applied read bias on WLs.  When the second read is initiated, the re-filled GBTs in the  first read are almost restored to the same level reached at the  end of the program operation. The FBC then returns to afterprogram values. The entire process is known to be highly  temperature-dependent since it is trap-dependent [8,23].

A device/circuit-level mitigation for TRE has been    proposed in [8] relying on voltage stress applied to the control  gates of the memory cells in the idle state (see Fig. 6). The  suppression of the GBTs discharging is obtained with small  biases (e.g., 2 V). Minor modifications to the 3D NAND Flash  peripheral circuitry are foreseen to implement that solution.  Another possible device solution is suppressing TRE through  the down coupling phenomenon (DCP) [9] that is commonly  present in 3D NAND Flash strings [24]. The dummy  wordlines close to the bitline and sourceline selectors are  optimized to have all the transistors in that location with a  threshold voltage of up to 4 V. When the program operation  ends, the DCP occurs as soon as the bias voltage drops below  that threshold voltage value. This results in a channel potential  drop towards negative values (e.g., -4 V) with the same effect  as a gate stress, proficiently suppressing TRE.

The impact of the TRE mitigation in storage architectures  has been assessed at the system level simulating a TLC 3D  NAND Flash-based SSD architecture using the emulator  described in [25]. The simulated SSD controller implements  an ECC correcting up to 120 FBC on 1 KB-sized codeword  with advanced secondary error correction schemes such as  soft-decoding. We must recall that soft-decoding should be  avoided as it is extremely performance-penalizing in the SSD  read operations. Fig. 7 shows that mitigating the TRE would  reduce the amount of soft-decoding operations. If dedicated  device/circuit/system solutions are not pursued, its presence  materializes in a 2 ms SSD latency increase with evident  drawbacks on the storage read latency Quality-of-Service  (QoS).

## C.   Cross-temperature mitigation through tracking  

The cross-temperature issue has been known since planar  NAND Flash technology [6,26,27]. Its nature is deep in the  memory cells' current dependency on the temperature that  affects the verification operation (i.e., a read operation within  the program flow) during the program algorithm or the simple  read. A high FBC is therefore induced when the memory is  read at a temperature different from the one experienced while  programming [27]. To mitigate such effects many solutions  were developed in the past. At the circuit level, the common  solution implemented in the peripheral circuitry of a 3D  NAND Flash chip is a temperature compensation circuit [28].  Its goal is to track the temperature variations in the memory  and adapt the read reference voltages ad-hoc to lower the FBC.  While this method appears efficient for most crosstemperature situations arising during memory usage, those  circuits cannot entirely compensate for this issue, especially if

The simplest approach uses dedicated 3D  NAND Flash commands (i.e., Moving Read Reference - MRR  [10]) to adapt the read references post-temperature  compensation at run-time. However, this may produce a  significant implementation overhead in the memory controller  exposing some reliability concerns [6].

The work in [29] proposes an alternative solution using a  dynamic algorithm that exploits the synergy of the 3D-TLC  NAND Flash memory with a smart system like an SSD  controller, namely the Cross-Temperature VTH Tracking  (CTDVT) algorithm. Fig.8 is an example of this  implementation. The controller runs a background algorithm  called read voltage reference centering (VRC) that locates the  optimal value to assign to read references for every  wordline/layer of a 3D-TLC NAND Flash according to the  wear status of the memory (an example of this algorithm was  proposed in [30]). The controller then detects the presence of  the cross-temperature condition using the on-chip temperature  sensors in the drive. The CTDVT algorithm is called at this  point and runs. It selects the optimal read reference voltages  (like the MRR) from a look-up table stored in the DRAM  buffer of the SSD to be applied to the different 3D NAND  Flash topological locations. However, the starting point of the  read reference modification for FBC lowering is calculated by  the VRC and not fixed by the Flash vendor. This will ensure a  true tracking of the FBC induced only by the crosstemperature without considering the artifacts produced by the  memory wearout. Further, the spread of the optimal read  reference voltage values is significantly reduced lowering the  probability of choosing an erroneous value for FBC  mitigation. Different approaches of the CTDVT algorithm can  be implemented in the storage controller as shown in Fig. 9.  All the reliability tests demonstrated the mitigation of the  cross-temperature induced FBC. ##  IV. MACHINE LEARNING AND ARTIFICIAL INTELLIGENCE FOR   3D NAND FLASH RELIABILITY 

The FSP algorithms implemented in the storage  controllers use various aids such as custom hardware  accelerators and firmware. Despite this, developing these  algorithms for 3D NAND silicon involves a lengthy  characterization process that generates large amounts of data  for analysis. The challenge arises when dealing with hundreds  of layers, as selecting easy-to-implement algorithms becomes  difficult due to the numerous options. This represented the  turning point for storage designers, leading them to explore  machine-learning techniques for 3D NAND Flash memory  reliability improvement. Designers faced similar obstacles  even in the final stages of planar NAND Flash technology  development. Early literature, such as works in [31,32],  highlighted the role of machine learning in addressing these  challenges. The introduction of 3D NAND Flash technology  and the growing influence of artificial intelligence in the  storage industry have sparked interest in utilizing techniques  like unsupervised clustering and neural networks for data  analysis and prediction. This section briefly examines the use  of these techniques in specific 3D NAND Flash test scenarios,  each with unique implementation goals such as real-time  predictions or offline model development.

The work in [33] used an unsupervised machine learning  algorithm such as the k-means to study the endurance stress  reliability of a commercially available TLC 3D NAND Flash  product. The objective was to identify memory regions in the  chip that exhibit similar behavior under stress testing, to  devise an effective ECC strategy tailored for each memory  location. When data clustering is implemented, it is  discovered that the ECC code rate can be customized for each  TLC page type and cluster, resulting in a  $24\%$   increase in the  storage addressable space.

## V.   C ONCLUSIONS 

In this work, we presented how to address the reliability  improvement process in 3D NAND Flash memory for  efficient storage architectures using a cross-layer approach.  We have shown some methodologies reducing the FBC for  different working conditions of the memory using FSP  algorithms either on-chip or off-chip combining device,  circuit, and system optimizations. Future works in this  context will also consider the potentialities of machine  learning and artificial intelligence to help storage designers  develop high-performance, energy-efficient, and extremely  reliable products based on the 3D NAND Flash technology.
